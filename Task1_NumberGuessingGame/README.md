# Task 1 - Number Guessing Game

## Objective

Develop a basic text-based game using conditional statements
for game logic.

## Description

The Number Guessing Game generates a random number between
1 and 100. The user has to guess the number.

The program provides hints such as "Too high" or "Too low"
until the user guesses the correct number.

## Features

- Random number generation
- User input validation
- Range validation
- Too high / too low hints
- Attempt counter
- Play again option
- Error handling for invalid input

## Technologies Used

- Java
- Scanner
- Random
- Conditional statements
- Loops
- Exception handling

## How to Run

Compile:

javac NumberGuessingGame.java

Run:

java NumberGuessingGame
