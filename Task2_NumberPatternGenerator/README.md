# Task 2 - Number Pattern Generator

## Objective

Generate and print different number patterns using loops.

## Description

This program allows the user to select a number pattern and
specify the number of rows. The program generates the selected
pattern using loops and nested loops.

## Patterns Included

1. Increasing Number Pattern
2. Repeated Number Pattern
3. Number Pyramid

## Input Validation

The program handles:

- Invalid menu input
- Alphabetic input
- Special characters
- Negative numbers
- Zero rows
- Rows greater than 20

## Concepts Used

- for loops
- Nested loops
- switch statement
- Conditional statements
- Scanner
- Exception handling
- Input validation

## Technologies Used

Java

## How to Run

Compile:

javac NumberPatternGenerator.java

Run:

java NumberPatternGenerator
